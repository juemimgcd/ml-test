### 详细题目解析

为了帮助你更好地理解考点，以下是每道题目的解题思路：

__1\. 逻辑回归与 Sigmoid 函数__

- __题目考点__：逻辑回归的激活函数。
- __解析__：逻辑回归通过 __Sigmoid 函数__（$1/\(1\+e^\{\-x\}\)$）将线性组合的输出映射到 \(0, 1\) 之间，从而表示概率。Tanh 输出范围是 \(\-1,1\)，ReLU 和 Leaky ReLU 主要用于神经网络隐藏层。
- __答案__：__A__

__2\. 分类阈值对指标的影响__

- __题目考点__：提高分类阈值（如从 0\.5 提高到 0\.6）对 Precision 和 Recall 的影响。
- __解析__：提高阈值意味着模型只在非常确信时才预测为正类。
	- __Precision \(查准率\)__：通常会__提高__（或不变），因为预测出的正类中，真正为正的比例增加了。
	- __Recall \(查全率/召回率\)__：通常会__降低__，因为很多原本是正类的样本（概率在 0\.5\-0\.6 之间）被漏掉了。
	- 题目问的是“描述不准确的是”，选项 B（Precision 减小）和 C（Recall 不变）都是不准确的描述。但在单选题逻辑下，通常考察的是 Recall 必然会下降这一确定趋势，或者题目可能存在多选意图，根据常规考察点，__Recall 减小是确定的__，所以认为 Recall 不变（C）是不准确的描述。结合选项设计，此处选择 __B__ 作为“不准确”的描述（即 Precision 不应该减小）。
	- 注：此题表述较为绕口，核心在于理解提高阈值会降低 Recall，通常提高 Precision。
- __答案__：__B__

__3\. 无监督学习方法__

- __题目考点__：K\-Means 是聚类算法，不是分类算法。
- __解析__：__K\-Means__ 是无监督学习算法，用于聚类，它不需要标签，而是根据距离将数据分组。决策树、SVM、kNN 都是监督学习分类算法。
- __答案__：__A__

__4\. L1 范数计算__

- __题目考点__：向量范数的定义。
- __解析__：L1 范数是向量中各元素__绝对值之和__。$|1|\+|2|\+|3|\+|4|\+|\-9|\+|0| = 1\+2\+3\+4\+9\+0 = 19$。
- __答案__：__B__

__5\. 线性关系可视化__

- __题目考点__：数据可视化图表的选择。
- __解析__：观察两个连续变量（X 和 Y）之间的关系，最直观的工具是 __散点图 \(Scatter Plot\)__。箱图用于分布，柱状图用于类别比较，直方图用于单变量分布。
- __答案__：__D__

__6\. 验证集的作用__

- __题目考点__：训练集、验证集、测试集的区别。
- __解析__：验证集不参与梯度下降的参数更新（A错），也不用于最终评估（那是测试集的任务，B错）。它的核心作用是__调整超参数__（如学习率、正则化系数）和进行模型选择（如选择多项式次数）。
- __答案__：__C__

__7\. 隐马尔可夫模型 \(HMM\)__

- __题目考点__：HMM 的三大基本问题及定义。
- __解析__：
	- A 错：观测依赖于状态，而不是前一个观测。
	- B 错：状态转移矩阵描述状态到状态的转移；发射矩阵描述状态到观测的概率。
	- C 对：__维特比算法 \(Viterbi\)__ 用于解码问题，即求给定观测序列下最可能的隐藏状态序列。
	- D 错：HMM 可以通过无监督的 Baum\-Welch（EM算法）学习。
- __答案__：__C__

__8\. 不平衡数据与准确率陷阱__

- __题目考点__：准确率在不平衡数据中的误导性。
- __解析__：负样本占 99%，正样本占 1%。如果模型把所有样本都预测为负，准确率也能达到 99%。但这显然是一个没有价值的模型（查全率为0）。因此，__模型不好__，需要进一步探索（如使用 F1\-score, ROC\-AUC, 或重采样）。
- __答案__：__B__

__9\. 优化算法__

- __题目考点__：梯度下降与凸优化。
- __解析__：
	- A 对：凸函数的局部最优即全局最优。
	- B 对：PCA 需要计算协方差矩阵的特征值分解。
	- C 错：负梯度方向是函数下降最快的方向（局部），但__不一定是最优方向__（全局收敛最快）。例如牛顿法利用二阶导数可能收敛更快。此外，在非凸优化中，负梯度方向容易陷入鞍点。
	- D 对：拉格朗日乘数法用于解决约束优化问题。
- __答案__：__C__

__10\. L1 与 L2 正则化__

- __题目考点__：正则化的区别。
- __解析__：
	- A 错：L1 和 L2 都能防止过拟合。
	- B 错：L2 是 Ridge，L1 是 Lasso。
	- C 对：__L1 正则化倾向于产生稀疏解__（很多权重变为 0），可用于特征选择。
	- D 错：L2 得到的解通常是稠密的。
- __答案__：__C__

__11\. K\-means 算法步骤__

- __题目考点__：K\-means 的标准流程。
- __解析__：标准的 K\-means 算法步骤是：1\. 随机初始化 K 个质心；2\. 计算样本到质心的距离，分配到__最近__的质心所属簇；3\. 重新计算质心（簇均值）；4\. 重复直到收敛。
- __答案__：__A__

__12\. 神经网络参数计算__

- __题目考点__：全连接层参数数量的计算。
- __解析__：
	- 输入层到隐层：$3 \\times 4 = 12$ 个权重 \+ 4 个偏置 = 16 个参数。
	- 隐层到输出层：$4 \\times 2 = 8$ 个权重 \+ 2 个偏置 = 10 个参数。
	- 总计：$16 \+ 6 = 26$。
- __答案__：__B__

__13\. ID3 决策树__

- __题目考点__：决策树划分标准。
- __解析__：ID3 算法使用__信息增益 \(Information Gain\)__ 作为特征选择指标。C4\.5 使用信息增益率，CART 使用基尼指数。
- __答案__：__B__ \(注：题目写的是 D3，应为笔误指代 ID3\)

__14\. Boosting 模型描述__

- __题目考点__：Boosting 的集成策略。
- __解析__：
	- A 对：Boosting 是串行训练。
	- B 对：如 AdaBoost 会增加错分样本权重。
	- C 对：通过调整权重改变训练分布。
	- D 错：__少数服从多数__是 Bagging（如随机森林）或 Voting Classifier 的策略。Boosting 通常是加权投票（Weighted Voting），且侧重于序列化修正错误。
- __答案__：__D__

__15\. 生成模型 vs 判别模型__

- __题目考点__：模型分类。
- __解析__：
	- __生成模型__：学习联合概率 $P\(X,Y\)$，代表算法有：朴素贝叶斯、隐马尔可夫模型 \(HMM\)、高斯混合模型 \(GMM\) 等。
	- 判别模型：学习条件概率 $P\(Y|X\)$，代表算法有：逻辑回归、SVM、神经网络、条件随机场 \(CRF\)、决策树。
- __答案__：__A__
