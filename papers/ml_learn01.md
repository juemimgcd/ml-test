# 机器学习聚类考点总结

基于课件 `机器学习-02-聚类-思政版.pptx` 的文字内容整理，并结合 `ml_test/references/exam-topics.md` 的历年题主题做了考试导向压缩。下面优先写期末最可能考的内容，不按课件页码复述。

说明：本总结主要依据 PPT 中可提取的文字层内容，图片、流程图和示意图只做了保守归纳。

## 一、必会考点

### 1. 聚类的基本定义与任务

- 聚类是无监督学习，目标是按样本之间的相似性把数据分成若干簇。
- 理想聚类结果是：簇内样本尽量相似，簇间样本尽量不同。
- 聚类的关键前提有两个：
  - 有样本集。
  - 有相似性度量方式，也就是距离度量或相似度度量。

易考点：
- 监督学习 vs 无监督学习的区别。
- 聚类任务的目标表述：不是预测标签，而是发现数据内部结构。

### 2. K-means 算法

高频程度：高。课件讲得最细，历年题也明确出现 `K-means`、`SSE`。

#### 核心思想

- 先指定簇数 `k`。
- 不断重复两步，直到收敛：
  - 把每个样本分到最近的簇中心。
  - 用簇内所有样本的均值更新簇中心。

#### 优化目标

- K-means 的目标是让每个样本点到所属簇中心的距离平方和尽量小。
- 该目标函数就是 `SSE`（误差平方和，Sum of Squared Errors）。

公式层面要会：
- `SSE = 所有样本到各自簇中心的距离平方和`
- 若使用欧氏距离，则簇中心是该簇样本的均值。

#### 必背性质

- `k` 需要事先指定。
- K-means 通常使用欧氏距离。
- K-means 倾向于找到“球状”或“凸形”簇。
- 对初始簇中心敏感。
- 容易陷入局部最优。
- 对离群点和特征尺度敏感。

#### 常考陷阱

- `k-means` 是聚类，不是分类。
- `k-means` 中的 `k` 表示簇数，不是 `kNN` 中的邻居数。
- `SSE` 越小通常表示簇内更紧密，但不能单独说明聚类一定最好，因为 `k` 增大时 `SSE` 往往会继续下降。

### 3. 距离度量

高频程度：高。聚类题常考“该用什么距离”“不同距离的含义”。

课件明确出现的距离/相似度：
- 欧氏距离
- 闵可夫斯基距离
- 曼哈顿距离
- 切比雪夫距离
- 余弦相似度
- 混合加权距离

必须掌握：
- 欧氏距离：直线距离，K-means 中最常见。
- 曼哈顿距离：各维绝对差之和。
- 切比雪夫距离：各维差值绝对值的最大值。
- 余弦相似度：衡量方向是否相近，适合看“趋势相似性”。

常见问法：
- 给两点，判断哪种距离更合适。
- 问余弦相似度与欧氏距离的区别。
- 问不同特征量纲差异很大时为什么要做归一化。

### 4. 特征归一化

高频程度：高。常作为概念题或简答题。

- 当不同特征的取值范围差异很大时，大尺度特征会主导欧氏距离。
- 因此在聚类前常需要做标准化或归一化。
- 课件强调：为了让不同特征有相近影响力，应先做预处理。

易考点：
- 为什么身高和体重若不归一化，会导致距离判断失真。
- 为什么基于距离的算法通常更依赖归一化。

### 5. 聚类评价指标

高频程度：中高。历年题明确爱考“指标辨析”。

#### 课件重点指标

- 轮廓系数 `Silhouette Coefficient, SC`
- DB 指数 `Davies-Bouldin Index, DBI`
- Dunn 指数 `DI`

#### 必会结论

- 轮廓系数：越大越好。
  - 含义：簇内更紧、簇间更分离。
- DBI：越小越好。
  - 含义：簇内平均距离更小、簇间中心更远。
- Dunn 指数：越大越好。
  - 含义：簇间距离相对更大、簇内最坏情况更紧凑。

常考方式：
- 选择题直接问“哪个指标越大越好/越小越好”。
- 给出指标含义，反推指标名称。
- 比较两个聚类结果时，判断哪个更优。

### 6. DBSCAN 算法

高频程度：高。历年题明确出现 `DBSCAN`，也是本章第二大重点。

#### 核心思想

- DBSCAN 是基于密度的聚类算法。
- 它不是预先指定 `k`，而是通过局部邻域密度来形成簇。

#### 两个核心参数

- `eps`：邻域半径。
- `MinPts`：成为核心点所需的最少邻域样本数。

#### 必背概念

- 核心点 `core point`：在 `eps` 邻域内样本数不少于 `MinPts`。
- 边界点 `border point`：自身不是核心点，但落在某核心点的邻域中。
- 噪声点 `noise`：不属于任何簇的点。
- 直接密度可达
- 密度可达
- 密度相连

#### 必会结论

- DBSCAN 可以识别噪声点。
- DBSCAN 不需要事先指定簇数。
- DBSCAN 更适合任意形状簇。
- 当不同区域密度差别很大时，DBSCAN 效果可能变差。

常考陷阱：
- 边界点与核心点的“直接密度可达”不是对称的。
- 簇至少包含一个核心点。
- 参数 `eps` 和 `MinPts` 选得不合适，会导致全是噪声或簇被过度合并。

## 二、次重点考点

### 1. K-means 的进一步讨论与改进

课件涉及：
- 局部最优与全局最优
- `k` 值确定
- 二分 K-means
- `k-means++`
- `K-medoids`
- `Mini Batch K-means`

重点记忆：
- `k` 的确定常用肘部法：观察 `SSE` 随 `k` 增加的下降趋势，在拐点附近选 `k`。
- `k-means++`：优化初始中心选择，减弱对初值敏感的问题。
- 二分 K-means：通过不断“分裂”簇来降低 `SSE`，缓解普通 K-means 易陷入局部最优的问题。
- `K-medoids`：簇中心不是均值，而是簇中某个真实样本点。
- `MiniBatchKMeans`：用小批量样本近似优化，牺牲部分精度换速度。

考试中常见问法：
- 哪种方法是为了解决初始化敏感问题。
- 哪种方法适合大规模数据。
- 哪种方法的中心一定是样本点本身。

### 2. 聚类算法分类

课件把聚类方法分成：
- 划分聚类
- 密度聚类
- 层次聚类
- 网格聚类
- 模型聚类

对应记忆：
- K-means：划分聚类
- DBSCAN、OPTICS：密度聚类
- AGNES：层次聚类
- GMM：模型聚类

这类题常直接出选择题。

### 3. OPTICS

高频程度：中。课件有专章，但历年题里更高频的是 DBSCAN。

要会的不是全流程推导，而是与 DBSCAN 的关系：
- OPTICS 是 DBSCAN 的派生算法。
- 它通过核心距离、可达距离来描述数据的密度结构。
- 适合处理不同密度簇的问题，比固定单一 `eps` 的 DBSCAN 更灵活。

必须认识的概念：
- 核心距离 `core distance`
- 可达距离 `reachability distance`

课件中的 `sklearn` 参数提示：
- `max_eps`：邻域半径上限。
- `min_samples`：核心点最少邻居数。
- `eps`：最终分簇使用的距离标准。

### 4. AGNES 层次聚类

高频程度：中。常作为概念辨析题。

#### 核心思想

- AGNES 是凝聚型层次聚类。
- 初始时每个样本各自成簇。
- 每次合并最近的两个簇，直到达到预设簇数。

#### 需要掌握的簇间距离

- 簇最小距离 `single`
- 簇最大距离 `complete`
- 簇平均距离 `average`
- 簇中心距离
- `ward`

其中课件明确指出：
- `single` 对应簇最小距离
- `complete` 对应簇最大距离
- `average` 对应簇平均距离
- `ward` 选择“使偏差平方和增加最小”的两个簇合并

易考点：
- AGNES 属于自底向上的层次聚类。
- 不同 `linkage` 的含义要能对应上。

## 三、典型题型总结

### 1. 概念辨析题

常见问法：
- K-means 和 DBSCAN 的区别。
- 聚类与分类的区别。
- 欧氏距离与余弦相似度的区别。
- 核心点、边界点、噪声点的区别。
- 轮廓系数、DBI、Dunn 指数的优化方向。

### 2. 小计算题

常考内容：
- 两点间欧氏距离、曼哈顿距离。
- 根据若干样本求簇中心均值。
- 根据样本到簇中心的距离求 `SSE`。
- 根据 `eps` 和 `MinPts` 判断某点是不是核心点。

### 3. 算法比较题

必须能答出的比较：
- K-means：
  - 优点：简单、高效。
  - 缺点：要先给 `k`，对初值和异常点敏感，只适合较规则簇。
- DBSCAN：
  - 优点：不用预设 `k`，能处理噪声和任意形状簇。
  - 缺点：对参数敏感，不同密度场景下表现可能不稳定。
- AGNES：
  - 优点：能反映层次结构。
  - 缺点：计算代价通常更高。

### 4. sklearn 应用题

课件直接提到的类/函数：
- `KMeans`
- `k_means`
- `MiniBatchKMeans`
- `OPTICS`

复习时至少要知道：
- `KMeans` 对应经典 K-means。
- `MiniBatchKMeans` 用于更大规模数据。
- `OPTICS` 是密度聚类实现。
- 层次聚类常见参数包括 `n_clusters` 和 `linkage`。

## 五、最后速记版

考前如果只剩几分钟，至少记住下面这些句子：

- 聚类是无监督学习，目标是簇内紧密、簇间分离。
- K-means 反复做“分配样本到最近中心 + 用均值更新中心”。
- K-means 的目标函数是 `SSE`，通常越小越好。
- `k` 常用肘部法选择。
- 距离型聚类前常要做归一化。
- 轮廓系数越大越好，DBI 越小越好，Dunn 越大越好。
- DBSCAN 的两个核心参数是 `eps` 和 `MinPts`。
- DBSCAN 能识别噪声点，不需要预先指定簇数。
- AGNES 是自底向上的层次聚类。
- `single / complete / average / ward` 要能和簇间距离方式对应。

### 1. 24-25 试卷中的聚类题

置信度：高。

#### 例题 1：选择题中直接出现 K-means

原始提取片段：

```text
11 K-means ______
A.  K
B.
C.  K
D.
```

清洗后理解：

- 这题明确考到了 `K-means` 的基础性质。
- 选项提取损坏较重，但可以确定它不是计算题，更像是对 `K-means` 基本概念、参数 `K` 或算法性质的辨析题。
- 复习时应重点准备：
  - `K` 表示簇数，且需要预先指定。
  - `K-means` 的目标是最小化 `SSE`。
  - `K-means` 对初始中心和异常点敏感。

#### 例题 2：大题中直接考 K-Means、SSE 和 K 的选择

原始提取片段：

```text
50 --
//data
120 Yeast
1 K-Means  Yeast  SSE  K
 K
```

清洗后理解：

- 该题明确要求在 `Yeast` 数据集上使用 `K-Means`。
- 题目明确出现了 `SSE` 和 `K`，高概率是在考：
  - 使用 `SSE` 评估聚类效果。
  - 根据 `SSE` 的变化选择合适的 `K`。
  - 也就是课件中的肘部法思路。

这道题对应的复习重点：

- 会解释 `SSE` 的含义。
- 会说明为什么 `K` 增大时 `SSE` 往往下降。
- 会根据 `SSE-K` 曲线寻找“拐点”来选 `K`。

#### 例题 3：大题中直接考 DBSCAN 参数

原始提取片段：

```text
2 DBSCAN  MinPts 35
10
```

清洗后理解：

- 该题明确考到了 `DBSCAN`。
- 能可靠识别的是题干中出现了 `MinPts` 和数值 `35`，下一行还有一个数值 `10`，但由于提取损坏，无法 100% 确认它是 `eps=10` 还是另一处参数/条件。
- 因此这题至少在考：
  - `DBSCAN` 的参数含义。
  - `MinPts` 对核心点判定的作用。
  - 可能还要求结合另一个给定参数进行聚类。

这道题对应的复习重点：

- 会解释 `eps` 和 `MinPts`。
- 会判断核心点、边界点、噪声点。
- 会说明参数过大或过小时聚类结果会如何变化。
